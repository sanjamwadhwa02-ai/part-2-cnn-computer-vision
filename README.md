# Neural Network Analysis Assignment

## Objective
Build and analyze a feed-forward neural network for customer churn prediction.

## Dataset
customer_churn_nn.csv

## Tasks Completed
- Dataset exploration
- Missing value check
- Statistical summary
- Target variable distribution
- Data preprocessing
- Neural network model building
- Model training and evaluation
- Confusion matrix
- Classification report

## Libraries Used
- pandas
- numpy
- matplotlib
- seaborn
- scikit-learn
- tensorflow

## Model Architecture
Input Layer → Dense(32, ReLU) → Dense(16, ReLU) → Output Layer (Sigmoid)

## Evaluation
Model evaluated using:
- Accuracy
- Confusion Matrix
- Classification Report
